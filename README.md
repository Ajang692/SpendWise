# My Budget Tracker

## Project Description

My Budget Tracker is a simple web page that helps users record and view their expenses.

## What I Built

- A budget tracker heading and logo.
- An expense form where the user can enter an expense name and amount.
- A category dropdown with five categories: Food, Transport, Shopping, Bills, and Entertainment.
- An expenses table showing expense name, amount, and category.
- JavaScript that adds a new expense to the table when the form is submitted.
- A budgeting tips YouTube video embedded on the page.
- A collapsible "How to use this tracker" section using `<details>` and `<summary>`.
- CSS hover effects for table rows and a pointer cursor for the button.
- Advanced CSS selectors including descendant, direct-child, `:nth-child()`, and `:focus` selectors.

## Files

- `index.html` - Contains the structure and content of the webpage.
- `style.css` - Contains the page styling, hover effects, and advanced CSS selectors.
- `script.js` - Handles the form submission and adds new expenses to the table.

## How to Use

1. Open `index.html` in a web browser.
2. Enter an expense name and amount.
3. Select a category.
4. Click **Add Expense**.
5. The new expense will appear in the expenses table.
